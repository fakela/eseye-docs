# Monitoring and diagnostics

Monitor connectivity across all deployments, especially those with intermittent or mobile connections. Early detection of underperforming networks or routing problems helps you reduce service impact and costs.

The [AnyNet Connectivity Management Platform](../about-the-connectivity-management-platform.md) provides automated and self-service tools for managing IoT estates and device connectivity.

### Monitoring tools

The CMP helps you:

* Identify service issues early.
* Find the cause of common issues, such as supplier or routing failures.
* Report performance by service.

Eseye provides applications that store and display connection performance in different ways. You can also use APIs to create visualisation tools or machine-learning applications for device connectivity insights.
