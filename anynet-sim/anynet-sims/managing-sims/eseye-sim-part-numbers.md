# Eseye SIM part numbers

Eseye SIM cards now use a different underlying silicon, which means the following part numbers are superseded. The supply of the new variants is ongoing as existing stocks are replaced.

| Old Code | New Code | Form Factor           |
| -------- | -------- | --------------------- |
| ES5610   | ES5710   | 2FF/3FF               |
| ES5611   | ES5711   | 2FF/3FF               |
| ES5614   | ES5714   | 2FF/3FF (Brazil only) |
| ES5620   | ES5721   | MFF (Embedded)        |
| ES5630   | ES5730   | 2FF/3FF/4FF           |
| ES5631   | ES5731   | 2FF/3FF/4FF           |
| ES5644   | ES5744   | 2FF (Brazil only)     |

{% hint style="info" %}
There is no change to SIM card functionality. Eseye expects the SIM cards to work the same way as previously supplied cards.

If you have questions, contact your Account Manager.
{% endhint %}
