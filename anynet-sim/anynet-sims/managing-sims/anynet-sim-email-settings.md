# AnyNet SIM email settings

You can send emails using AnyNet SIM cards.

## Configuration settings

|                                        |               |
| -------------------------------------- | ------------- |
| SMTP Relay:                            | 192.168.111.3 |
| Port:                                  | 25            |
| Recommended From email address domain: | eseye.net     |

{% hint style="info" %}
The mail relay's external IP address resolves to `eseye.net`. Use `eseye.net` as the device's From email address domain to support negotiation with some email spam filters.
{% endhint %}
