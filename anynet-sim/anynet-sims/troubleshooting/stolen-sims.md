# Stolen SIMs

{% hint style="info" %}
Use [network usage monitoring](https://eseye-v3.gitbook.io/eseye-docs/L25WdLp1CEZBZ0aOlPAR/connectivity/monitoring-and-diagnostics/monitoring-and-administering-network-usage) to investigate anomalous activity from stolen SIMs.
{% endhint %}

Configure alerts for unexpected data usage and device disconnections. Suspend affected SIMs while you investigate.

Protect commands sent to the modem. Attackers can reverse engineer exposed commands and use them to access the device.
