# Enabling SIM Toolkit

For most current modules, SIM Toolkit is already enabled.

The table below shows the commands for enabling the SIM toolkit on some modems.

| Vendor          | Command   |
| --------------- | --------- |
| Telit           | AT#STIA=1 |
| Quectel         | AT+QSTK=1 |
| Sierra Wireless | AT+STSF=1 |
| Huawei          | AT^STSF=1 |
