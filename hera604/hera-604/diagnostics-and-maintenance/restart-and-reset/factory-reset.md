# Factory reset

Open **Diagnostics & Maintenance → Restart → Factory reset**, then select **Reset** to return the router to its factory configuration.

<figure><img src="../../.gitbook/assets/Screenshot 2026-08-14 at 17.00.03.png" alt="Restart page with the Factory reset button."><figcaption></figcaption></figure>

{% hint style="warning" %}
A factory reset removes the operational configuration. It can make the router unreachable at its previous address. Download a backup first. Use factory reset only when rebuilding the router or when Eseye Support instructs you to do so.
{% endhint %}

Before you reset the router, confirm that you have:

* An approved configuration backup.
* The initial access details and expected default LAN address.
* The settings needed to rebuild the router.
* On-site or direct local access.
* An approved outage window.
