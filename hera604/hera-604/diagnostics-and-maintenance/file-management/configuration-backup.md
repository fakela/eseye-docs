# Configuration backup

Open **Diagnostics & Maintenance → File Management → Configuration backup**, then select **Backup**.

<figure><img src="../../.gitbook/assets/Screenshot 2026-08-14 at 16.58.50.png" alt="File Management configuration backup page with the Backup button."><figcaption></figcaption></figure>

The browser downloads the current running configuration as a `.tar.gz` file. Your browser might request the router administrator credentials before downloading.

Store each backup securely. Label it with the router serial number, site, date, and software version. Configuration backups can contain sensitive network settings.
