# Settings

Open **Diagnostics & Maintenance → Data Logging → Settings** to control periodic performance-data collection.

<figure><img src="../../.gitbook/assets/Screenshot 2026-08-14 at 17.00.08.png" alt="Data Logging settings page showing logging status and log period."><figcaption></figcaption></figure>

| Field      | Description                                                                                    |
| ---------- | ---------------------------------------------------------------------------------------------- |
| Logging    | Enables or disables data logging.                                                              |
| Log period | Time between data-capture events. Shorter periods provide more detail and create more records. |
