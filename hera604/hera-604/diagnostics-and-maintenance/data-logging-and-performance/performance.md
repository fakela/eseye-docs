# Performance

Open **Diagnostics & Maintenance → Data Logging → Performance** to view logged mobile signal and traffic data.

<figure><img src="../../.gitbook/assets/Screenshot 2026-08-14 at 17.00.13.png" alt="Data Logging performance page showing mobile signal and traffic graphs."><figcaption></figcaption></figure>

Use the date and time controls to select a period. The graphs show:

* Mobile signal strength in dBm.
* Mobile data sent and received.
* The mobile network operator.

Hover over a graph point to view its value and timestamp. Compare events with router logs and site activity before drawing conclusions.
