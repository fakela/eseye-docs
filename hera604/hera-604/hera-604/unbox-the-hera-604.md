# Unbox the Hera 604

Before installation, check that the package contains all the following items:

| Item                                 | Quantity |
| ------------------------------------ | -------- |
| Hera 604 router                      | 1        |
| Wi-Fi antennas                       | 4        |
| Magnetic-mount cellular LTE antennas | 2        |
| Power supply                         | 1        |
| US power adapter                     | 1        |
| Ethernet patch cable                 | 1        |
| SIM card security plate              | 1        |

Confirm that every item is present before starting installation. If an item is missing, contact your supplier.

For the router panels, ports, connectors, and product label, see [Hera 604 panels and ports](hera-604-panels-and-ports.md).
