# System status

**System Status** displays operating and connection information for the Hera 604. It includes router identification, network-interface status, and equipment detected on the local network.

{% hint style="info" %}
**Read only.** System Status displays current information only. You cannot change the router configuration from these pages. Each page identifies where you configure its settings.
{% endhint %}

Values do not update automatically, select the **refresh** icon beside the relevant heading to retrieve the latest information.

### In this section

* [Router](router.md) — Identification details, software versions, system activity, and site information.
* [Local area network (LAN)](local-area-network-lan.md) — LAN address-assignment method, IP address, and net mask.
* [Wide area network (WAN)](wide-area-network-wan.md) — Address information for a configured Ethernet WAN connection.
* [Mobile network](mobile-network.md) — Cellular connection status, SIM identifiers, operator, IP address, signal strength, and APN.
* [Connected devices](connected-devices.md) — Equipment detected on the local network.
