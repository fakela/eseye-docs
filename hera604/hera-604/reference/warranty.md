# Warranty

## Warranty

Use Eseye-approved mains adapters only.

Do not open the enclosure. It contains no user-serviceable parts.

Follow every installation instruction. Incorrect installation can cause damage or injury.

{% hint style="warning" %}
Power off the router before inserting or removing an external SIM.
{% endhint %}

Keep the router in its supported environmental range. Protect it from liquids, excessive heat, and contaminants.
