# Glossary

## Glossary

* **2.4 GHz / 5 GHz** — Supported Wi-Fi radio bands.
* **802.11a/b/g/n/ac** — Supported Wi-Fi standards.
* **Access Point (AP)** — Wi-Fi mode that accepts client connections.
* **AnyNet Connectivity Service** — Eseye cellular connectivity service for IoT deployments.
* **APN** — Network identifier used for cellular data connections.
* **Auto MDI/MDIX** — Ethernet port feature that automatically crosses wire pairs.
* **AWS IoT** — Amazon Web Services IoT platform.
* **Bandwidth** — Wi-Fi channel width affecting rates and spectrum use.
* **Channel** — Radio channel used by the Wi-Fi interface.
* **CLI** — Command-line interface, accessed with SSH when enabled.
* **Client certificate** — Certificate that proves a device or user identity.
* **Default route metric** — Numeric route weight. Lower values have priority.
* **DER** — Binary encoding for X.509 certificates.
* **DHCP** — Protocol that automatically supplies network configuration.
* **DIN-rail mounting** — Optional mounting method for industrial rails.
* **DNS** — Service that resolves hostnames to IP addresses.
* **eSIM** — SIM embedded in the router.
* **eUICC** — SIM technology that supports remote profile provisioning.
* **Firewall** — Packet-filtering controls for network traffic.
* **Firmware** — Operating software running on the router.
* **Gateway** — Next-hop address for external networks.
* **GUI** — Browser-based management interface.
* **Health Monitor** — Service that tests connectivity and runs recovery actions.
* **Hostname** — Router name on the local network.
* **HTTP / HTTPS** — Unencrypted and encrypted web protocols.
* **ICCID** — Unique SIM card identifier.
* **IMEI** — Unique identifier for modem hardware.
* **IMSI** — Identifier for a cellular subscriber.
* **Inbound rules** — Rules that control access to router services.
* **Infinity Platform** — Eseye platform for billing and security features.
* **IPv4 / IPv6** — Internet Protocol address versions.
* **Kernel** — Core Linux component running on the router.
* **LAN** — Local network for connected devices.
* **MAC filter** — Allowlist or blocklist for Wi-Fi client addresses.
* **MCC/MNC** — Mobile country and network identifiers.
* **MTU** — Maximum Transmission Unit for a network connection.
* **NAT** — Translation between private and WAN addresses.
* **Netmask** — Value that defines an IP network range.
* **NTP** — Protocol that synchronises system time.
* **Outbound rules** — Rules that restrict LAN traffic leaving the router.
* **PEM** — Text encoding for X.509 certificates.
* **Port forwarding** — Mapping of a WAN port to a LAN address and port.
* **Limited Power Source (LPS)** — Approved power source meeting safety requirements.
* **Private key** — Secret key used for decryption and digital signatures.
* **TCP, UDP, ICMP, ESP** — Network protocols available in firewall rules.
* **Factory reset** — Restores factory configuration.
* **Reset button** — Physical control for rebooting or restoring defaults.
* **Root CA** — Trusted certificate authority at the top of a trust chain.
* **RSSI** — Cellular signal strength in dBm.
* **WEP, WPA-PSK, WPA-PSK2** — Wi-Fi security methods.
* **SIM PIN** — Optional numeric code protecting a SIM.
* **SMA antenna connector** — 50 Ω connector for cellular or Wi-Fi antennas.
* **SSH** — Secure remote command-line protocol.
* **SSID** — Wi-Fi network name.
* **SSID visibility** — Controls whether nearby clients can discover an SSID.
* **Static route** — Manually defined route to a destination network.
* **Status LEDs** — Power, Wi-Fi, WAN, and signal indicators.
* **Thing** — AWS IoT representation of a physical device.
* **Uptime** — Time since the router last booted.
* **URL** — Web address for a network resource.
* **WAN** — External network that reaches the internet or upstream services.
* **Wireless client / STA** — Mode where the router joins another Wi-Fi network.
