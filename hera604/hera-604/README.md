# About the Hera 604

The Hera 604 is an M2M-grade 3G/4G router for connecting IoT devices and remote assets over cellular, Wi-Fi and Ethernet networks. It is the LTE model in the Hera 600 series and supports automatic failover from Ethernet WAN to cellular.

Its aluminium enclosure makes it suitable for industrial and remote installations.

### Key features

* **Multi-network cellular connectivity:** The embedded Eseye AnyNet SIM provides access to more than 700 mobile networks across 190 countries. Two removable SIM slots provide additional connectivity options.
* **Automatic connectivity recovery:** The Health Monitor can optionally activate High Availability. If connectivity is lost, High Availability scans for available networks, then cycles through and tests each network until connectivity is restored.
* **Local device connectivity:** Four Gigabit Ethernet ports, concurrent Wi-Fi and two serial ports support different types of connected equipment.
* **Edge protocol conversion:** Included applications connect serial and Modbus equipment to MQTT and IP services.
* **Remote device management:** The DMS Management Server provides remote access to device configuration and status, including remote update options.

### Technical capabilities

| **Capability** | **Details**                                                                      |
| -------------- | -------------------------------------------------------------------------------- |
| Cellular       | Cat 13 LTE, with download speeds up to 400 Mbps and upload speeds up to 150 Mbps |
| SIM            | Embedded AnyNet SIM and two removable SIM slots                                  |
| Ethernet       | Four 10/100/1000 ports, with port 4 configurable as WAN or LAN                   |
| Wi-Fi          | Concurrent 2.4 GHz and 5 GHz 802.11ac Wave 2, with up to four SSIDs              |
| Serial         | Two RS232, RS422 or RS485 data ports, plus a management port                     |
| Networking     | Internal VLANs only, up to 16 LAN subnets, and DHCP server, client and relay     |
| Security       | Stateful firewall, IP filtering, NAT, NAPT and denial-of-service protection      |
| VPN            | IPsec tunnelling                                                                 |

### Included applications

The Hera 604 includes the following applications:

* Serial to IP
* AWS IoT
* UDP/TCP to MQTT
* Serial to MQTT
* Modbus to MQTT
* AnyNet Secure Cloud Connection

### Connected services

| **Service**           | **Description**                                                                       |

| AnyNet SMARTconnect   | Maintains secure connectivity and service availability across cellular networks       |
| DMS Management Server | Provides remote access to device configuration and status, with remote update options |

### Common use cases

The Hera 604 supports deployments such as:

* Vending machines
* Digital signage
* EV charging points
* Industrial control panels
* Remote equipment that requires cellular connectivity or automatic failover
