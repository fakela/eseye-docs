# Connect Hera 604

Connect a computer to the Hera604 through Wi-Fi or Ethernet.

{% hint style="info" %}
Check that the Hera is mounted, powered on, and running. The Power, Wifi, Signal, LAN or Wan LED must be green.
{% endhint %}

### Connect over Wi-Fi

The Wi-Fi network name and passphrase are provided in the Quick Start Guide supplied with the Hera 604.

1. Check that the Wi-Fi LED on the Hera is lit.
2. On your computer, search for available wireless networks.
3. Select the network name shown in the Quick Start Guide.
4. Enter the passphrase exactly as printed, including capitalization.

Your computer connects to the Hera.

### Connect over Ethernet

Use an Ethernet cable to connect from the Hera Ethernet port Link2 to a PC or laptop, either directly or via an Ethernet switch.

{% hint style="info" %}
The Hera assigns an address to your computer automatically. Most computers already accept automatic addresses.
{% endhint %}

### If your Ethernet connection does not get an address

Set the Ethernet adapter to use automatic addressing:

{% tabs %}
{% tab title="Windows" %}
1. Open **Network Connections**.
2. In **Network Connections**, right-click the Ethernet adapter.
3. Select **Properties**.
4. In the adapter properties, select **Internet Protocol Version 4 (TCP/IPv4)**.
5. Select **Properties**.
6. Select **Obtain an IP address automatically**.
7. Select **Obtain DNS server address automatically**.
8. Select **OK**.
{% endtab %}

{% tab title="macOS" %}
1. Open **System Settings**.
2. In **System Settings**, select **Network**.
3. Select the Ethernet connection.
4. Select **Details**.
5. On the **TCP/IP** tab, set **Configure IPv4** to **Using DHCP**.
6. Select **OK**.
{% endtab %}
{% endtabs %}
