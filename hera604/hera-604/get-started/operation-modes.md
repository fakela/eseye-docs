# Operation modes

The Hera 604 supports mobile, Ethernet, and Wi-Fi connections.

Configure a primary WAN connection for internet access. You can also configure a backup WAN connection. If the primary connection fails, the router uses the backup connection.

### Available interfaces

| Interface | Primary WAN | Backup WAN | LAN |
| --------- | :---------: | :--------: | :-: |
| Mobile    |      ✓      |      ✓     |  ✗  |
| Ethernet  |      ✓      |      ✓     |  ✓  |
| Wi-Fi     |      ✓      |      ✓     |  ✓  |

Choose the interfaces that match your available connections. The following sections explain how to configure each connection type.
