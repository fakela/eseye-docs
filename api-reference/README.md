# Overview

The Eseye APIs and data services connect your applications and operational systems to Eseye's IoT connectivity platform. With it, you manage SIMs, retrieve location information, send SMS messages, analyse connectivity telemetry, and run bulk operations programmatically.

### Available APIs and data services

| API or service       | Use it to                                                                             | Commercial model   |
| -------------------- | ------------------------------------------------------------------------------------- | ------------------ |
| SIM API              | Manage SIM statuses, attributes, packages, billing information, and network activity. | Free               |
| Bulk Operations API  | Process large operations asynchronously through files and jobs.                       | Free               |
| Location API         | Retrieve estimated SIM locations and cell tower information.                          | Chargeable         |
| SMS API              | Send SMS messages, cancel messages, and check delivery status.                        | Chargeable         |
| Connectivity Metrics | Receive Authentication, Accounting, and NetFlow metrics through secure SFTP.          | Commercial service |

{% hint style="info" %}
Connectivity Metrics is a secure, file-based data feed, not a REST API.
{% endhint %}
