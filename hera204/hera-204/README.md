# About the Hera 204

The Hera 204 is an entry-level industrial 2G, 3G, and 4G router. It connects IoT devices and remote assets over cellular, Wi-Fi, and Ethernet networks.

Its compact aluminium enclosure and direct-mount design suit industrial and remote installations.

#### Key features

* **Multi-network cellular connectivity:** The embedded Eseye AnyNet eSIM provides access to more than 800 mobile networks across over 190 countries. An external SIM slot provides an additional connectivity option.
* **Automatic connectivity recovery:** The Health Monitor checks the router’s WAN interfaces. It can switch WAN interfaces, restart an affected interface, reset the cellular connection, change SIM profiles, or restart the router when required.
* **Local device connectivity:** An Ethernet port and Wi-Fi connectivity support local IoT devices and equipment.
* **Flexible WAN connectivity:** The Hera 204 supports cellular, Ethernet, and Wi-Fi WAN connections, with primary and backup connections available when an interface becomes unavailable.
* **Remote device management:** The Hera 204 supports remote monitoring and over-the-air updates through Eseye management services.
* **Compact industrial design:** The aluminium enclosure supports direct mounting and optional bottom or side DIN rail mounting.

#### Technical capabilities

| Capability        | Details                                                                                             |
| ----------------- | --------------------------------------------------------------------------------------------------- |
| Cellular          | 2G, 3G, and 4G connectivity                                                                         |
| SIM               | Embedded Eseye AnyNet eSIM and one external SIM slot                                                |
| Ethernet          | One 10/100 Mbps Ethernet port, configurable as WAN or LAN                                           |
| Wi-Fi             | IEEE 802.11a/b/g/n/ac, with speeds up to 867 Mbps                                                   |
| Wi-Fi bands       | 2.4 GHz 2×2 and 5 GHz 2×2, operating non-concurrently                                               |
| Wireless networks | Access point and client modes, with support for up to four SSIDs                                    |
| Wireless security | 64-bit and 128-bit WEP, WPA, and WPA2 encryption, SSID stealth mode, and MAC address access control |
| Firewall          | Inbound and outbound rules, and port forwarding                                                     |
| Hardware          | 1.3 GHz Cortex-A7 processor with 128 MB RAM                                                         |
| Power             | 9–24 V DC input and a maximum power consumption of 10 W                                             |
| Mounting          | Direct mounting or optional bottom or side DIN rail mounting                                        |

#### Included applications

The Hera 204 includes an AWS IoT application that connects the router to AWS IoT Core and supports downloading the required certificate files.

#### Connected services

| Service                            | Description                                                                                                      |
| ---------------------------------- | ---------------------------------------------------------------------------------------------------------------- |
| AnyNet Connectivity Service        | Provides managed global connectivity without requiring separate contracts with multiple mobile network operators |
| Infinity IoT Connectivity Platform | Provides consolidated connectivity management, billing, and security                                             |
| Eseye device management system     | Supports remote monitoring, automatic configuration, and over-the-air updates                                    |
