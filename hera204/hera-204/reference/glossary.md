# Glossary

* **2.4 GHz / 5 GHz** — Radio bands supported; band selection depends on hardware mode and bandwidth settings.
* **802.11a/b/g/n/ac** — WiFi standards supported; selectable via hardware mode and bandwidth options.
* **Access Point (AP)** — Mode where the router provides WiFi for clients to join.
* **AnyNet Connectivity Service** — Eseye's global cellular service for IoT deployments.
* **APN (Access Point Name)** — Network identifier the device uses to connect to a carrier's data service; configured per cellular profile.
* **Auto MDI/MDIX** — Ethernet feature that autocrosses pairs so standard cables work for either role.
* **AWS IOT** — Amazon Web Services Internet Of Things
* **Bandwidth** — Channel width that affects data rates and spectrum use.
* **Channel (Auto/Manual)** — RF channel used by the radio; availability depends on country and mode.
* **CLI** — Command-line interface accessible via SSH when permitted.
* **Client Certificate** — A digital certificate that verifies a device or user's identity to a server.
* **Default Route Priority / Metric** — Numeric weight that prefers one default route over another when multiple exist.
* **DER** — A file format containing the X.509 certificate encoded in binary form.
* **DHCP** — Protocol that automatically assigns IP configuration; the router can run a DHCP server for LAN devices.
* **DIN rail Mounting** — Optional kit for mounting the device on DIN rails (bottom/sideways).
* **DNS (Domain Name System)** — Resolves hostnames to IP addresses; also used in connectivity tests.
* **eSIM** — Embedded SIM built into the device; Hera 204 also has a removable SIM slot.
* **eUICC** — SIM technology that supports remote provisioning of multiple profiles.
* **Firewall** — Built-in packet filtering to control inbound and outbound traffic.
* **Firmware** — Operating software running on the router; reported in System Status.
* **Gateway** — Next-hop address used to reach networks outside the local subnet.
* **GUI** — Web-based management interface (Graphical User Interface).
* **Health Monitor** — Connectivity monitoring that can restart interfaces, switch profiles, or reboot to restore service.
* **Hostname** — Name assigned to the router for identification on the network.
* **HTTPS / HTTP** — Encrypted (443) and unencrypted (80) web access referenced in firewall examples and blocks.
* **ICCID** — Integrated Circuit Card Identifier; unique identifier of a SIM card.
* **IMEI** — International Mobile Equipment Identity; unique identifier for the modem hardware.
* **IMSI** — International Mobile Subscriber Identity; identifies the subscriber on the cellular network.
* **Inbound Rules** — Open or restrict access to services on the router (e.g., HTTPS 443, SSH 22, ICMP Ping).
* **Infinity Platform** — Eseye's platform for consolidated billing and security features for IoT.
* **IPv4 / IPv6** — Internet Protocol versions referenced for name resolution and connectivity options.
* **Kernel** — Linux kernel version currently running on the device.
* **LAN (Local Area Network)** — Local network segment for client devices connected to the router.
* **MAC Filter (Allow/Deny)** — Whitelist/blacklist of client MAC addresses permitted to associate.
* **MCC/MNC** — Mobile Country Code and Mobile Network Code used to specify a particular cellular provider.
* **MTU** — Maximum Transmission Unit; size parameter available when using PPPoE.
* **NAT (Network Address Translation)** — Translates private LAN addresses to a public/WAN address.
* **Netmask / Subnet mask** — Defines the size of an IP network (e.g., 255.255.255.0).
* **NTP (Network Time Protocol)** — Synchronizes the router's system time with configured servers; client/server options available.
* **Outbound Rules** — Restrict LAN clients from reaching specific IPs/ports/protocols.
* **PEM** — A file format containing the X.509 certificate encoded in text form (base64 and encrypted).
* **Port Forwarding / Redirection** — Maps an external WAN port to a specific LAN IP/port to enable remote access.
* **Power Supply (LPS, 9–24 VDC)** — Uses a Limited Power Source adapter; accepts 9–24 VDC input (12 V wall adapter supplied).
* **Private Key** — A secret cryptographic key used to decrypt data and prove identity via digital signatures.
* **Protocols: TCP, UDP, ICMP, ESP** — Transport/network protocols selectable in firewall rules.
* **Reboot / Factory Reset** — Maintenance actions to restart the router or restore factory defaults (via UI or reset button).
* **Reset Button** — Physical button that can reboot or trigger a factory reset depending on press duration.
* **Root CA** — A trusted authority at the top of a certificate chain that signs and validates other certificates.
* **RSSI** — Received Signal Strength Indicator; cellular signal level reported in dBm.
* **Security (WEP, WPA-PSK, WPA-PSK2)** — Encryption/authentication options for protecting the WiFi network.
* **SIM PIN** — Optional numeric code that protects a SIM; incorrect entry may block the SIM.
* **SMA Antenna Connectors (50 Ω)** — RF connectors for cellular (primary/diversity) and WiFi antennas.
* **SSH** — Secure remote login protocol; used to access the router's CLI when enabled.
* **SSID (Service Set Identifier)** — WiFi network name clients see and join; requires a passphrase when security is enabled.
* **SSID Visibility (Broadcast/Hidden)** — Controls whether the SSID is visible in scans or must be entered manually.
* **Static Route** — Manually configured route specifying destination, mask, interface, gateway, and cost.
* **Status LEDs (Power, WiFi, WAN, Signal)** — Indicators for power/software state, WiFi/WAN availability/activity, and cellular signal strength.
* **Thing (AWS IoT)** — A virtual representation of a physical device within AWS IoT used for identity and management.
* **Uptime** — Time elapsed since the device last booted.
* **URL** — The web address used to locate and access a resource on a network.
* **WAN (Wide Area Network)** — External network used to reach the internet or upstream networks.
* **Wireless Client / STA mode** — Mode where the device connects to another WiFi network as a client.
