# File management

Back up the running configuration, upload a configuration archive, or upload a software package.

### Configuration backup

In **File Management**, click **Backup**. Your browser downloads the running configuration as a `tar.gz` archive.

### Configuration upload

{% stepper %}
{% step %}
#### Select the archive

In **Configuration Upload**, click **Upload**. Click **Choose File**, then select a `tar.gz` configuration archive.
{% endstep %}

{% step %}
#### Apply the configuration

Click **OK**. Choose whether to reboot immediately or later.
{% endstep %}
{% endstepper %}

### Software upload

In **Software Upload**, click **Upload**, then **Choose File**. Select the `tar.gz` software archive. The router installs the package, reboots, and applies it.
