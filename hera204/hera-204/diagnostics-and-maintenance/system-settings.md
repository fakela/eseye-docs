# System settings

### Network Time Protocol (NTP)

Configure the NTP client and local NTP server. Set NTP servers, address-resolution behavior, and minimum and maximum polling times.

![Network Time Protocol settings](https://733576849-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2FY2LsJ6998Uo7AtYcmJWd%2Fuploads%2FKFShvyHuHYYPBu0JMpPN%2Fnetwork_time_protocol_ntp_figure.png?alt=media\&token=c70bb85e-0ddb-40fe-bbc7-cd9d969f8209)

| Setting            | Description                                  |
| ------------------ | -------------------------------------------- |
| Local NTP server   | Enables or disables the local server.        |
| NTP servers        | Lists servers used by the NTP client.        |
| Address resolution | Uses IPv4 only, or IPv4 and IPv6.            |
| Poll time          | Sets the minimum and maximum poll intervals. |

Removing every NTP server disables the NTP client.
