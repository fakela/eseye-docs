# Data logging and performance

Data logging records statistical data over time. Performance graphs show mobile signal strength and transferred data for a selected date and time range.

### Data logging settings

Enable or disable logging. Set the log period in seconds to control the interval between capture events.

![Data Logging settings](https://733576849-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2FY2LsJ6998Uo7AtYcmJWd%2Fuploads%2F6yAKH1nIMZHzonWWJFXA%2Fsettings_figure.png?alt=media\&token=56ac27c5-e873-45a7-88c6-14bce333e880)

| Setting    | Description                              |
| ---------- | ---------------------------------------- |
| Logging    | Enables or disables data logging.        |
| Log period | Sets the seconds between capture events. |

### Performance

Hover over a graph point to view its value and timestamp. Hover over the network operator bar to view the connected mobile network.
