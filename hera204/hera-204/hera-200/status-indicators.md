# Status indicators

Use the status indicators on the front panel to check the power, Wi-Fi, WAN, and cellular signal status of the Hera 204.

### Power indicator

| **State**                                     | **Description**                                                                 |
| --------------------------------------------- | ------------------------------------------------------------------------------- |
| Solid red                                     | The router is powered, but the software is not operating yet.                   |
| Solid green                                   | The router is powered and the software is operating normally.                   |
| Flashing green in sync with another indicator | There is an error on the interface represented by the other flashing indicator. |
| Flashing green independently after startup    | There is an internal error.                                                     |
| Off                                           | There is no mains power, or the router has failed.                              |

### Wi-Fi indicator

| **State**                                                 | **Description**                           |
| --------------------------------------------------------- | ----------------------------------------- |
| Solid green                                               | A Wi-Fi connection is available.          |
| Flashing green regularly in sync with the Power indicator | There is an error on the Wi-Fi interface. |
| Flashing green irregularly                                | Wi-Fi data is being transferred.          |
| Off                                                       | No Wi-Fi connection is available.         |

### WAN indicator

| **State**                                                 | **Description**                         |
| --------------------------------------------------------- | --------------------------------------- |
| Solid green                                               | A WAN connection is available.          |
| Flashing green regularly in sync with the Power indicator | There is an error on the WAN interface. |
| Flashing green irregularly                                | WAN data is being transferred.          |
| Off                                                       | No WAN connection is available.         |

### Signal indicator

| **State**                          | **Description**                 |
| ---------------------------------- | ------------------------------- |
| Brief red flash every five seconds | No cellular signal is detected. |
| Solid red                          | The cellular signal is weak.    |
| Solid orange                       | The cellular signal is medium.  |
| Solid green                        | The cellular signal is strong.  |
| Off                                | The cellular modem is off.      |

For the location of each indicator, see [hera-204-panels-and-ports.md](hera-204-panels-and-ports.md "mention").
