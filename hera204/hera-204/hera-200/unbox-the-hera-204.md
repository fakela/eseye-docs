# Unbox the Hera 204

Before installation, check that the package contains all the following items:

| **Item**              | **Quantity** |
| --------------------- | ------------ |
| Hera 204 router       | 1            |
| Cellular antennas     | 2            |
| Wi-Fi antennas        | 2            |
| 12 V DC power adapter | 1            |
| Fulfilment insert     | 1            |

The fulfilment insert contains the router’s IP address, username, and password. You need this information when you first log in.

Confirm that every item is present before starting the installation. If an item is missing, contact your supplier.

{% hint style="info" %}
The Hera 204 has an embedded Eseye AnyNet eSIM. An additional external SIM is only required when your deployment uses one.
{% endhint %}

For router panels, ports, and connectors, see [hera-204-panels-and-ports.md](hera-204-panels-and-ports.md "mention").
