# Connect Hera 204

To access the Hera 204 web interface, use a computer connected to the router.

Choose one of the following connection methods.

### Connect over Wi-Fi

1. Check that Wi-Fi is enabled on the Hera 204.
2. On your computer, open the list of available Wi-Fi networks.
3. Select the Hera 204 Wi-Fi network.
4. Enter the Wi-Fi passphrase when prompted.

Your computer connects to the Hera 204.

### Connect over Ethernet

Connect an Ethernet cable between your computer and the Hera 204.

The Hera 204 automatically assigns an IP address to your computer. Most computers obtain an IP address automatically.

#### If your Ethernet connection does not get an IP address

Configure the Ethernet adapter to obtain an IP address automatically:

{% tab title="macOS" %}
1. Open **System Settings**.
2. Select **Network**.
3. Select the Ethernet connection connected to the Hera 204.
4. Select **Details**.
5. Select **TCP/IP**.
6. Set **Configure IPv4** to **Using DHCP**.
7. Select **OK**.
{% endtab %}
{% endtabs %}

### Access the web interface

1. Open a web browser.
2.  In the address bar, enter the Hera 204 IP address:

    `http://192.168.0.1`
