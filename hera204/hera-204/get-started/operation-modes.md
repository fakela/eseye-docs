# Operation Modes

The Hera 204 series router supports various operation modes. It can be connected to the internet (WAN) via mobile, standard Ethernet cable or via a wireless network. When connecting to the internet, you may also backup your main WAN connection with a backup connection. Initially, the router uses its Primary WAN connection. If the Primary connection fails to connect then the router will connect via the secondary connection.

| WAN Interface | Main WAN | Backup WAN | LAN |
| ------------- | -------- | ---------- | --- |
| Mobile        | ✓        | ✓          | ✗   |
| Ethernet      | ✓        | ✓          | ✓   |
| Wi-Fi         | ✓        | ✓          | ✓   |

Subsequent sections will provide detailed instructions on configuring the router to operate in the preferred mode.
