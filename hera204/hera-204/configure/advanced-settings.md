# Advanced Settings

The 'Advanced settings' page can be used to directly edit the UCI configuration files of the Hera 204 router. Only advanced users should use this section as incorrect input may hinder the performance or operation of the Hera 204 router.

You can view and edit the files from each of the following pages. To edit a file, select it within the 'Contents' menu, then click the 'Edit' button in the top-right corner of the page. After making changes, you can either reset the file back to default with the 'Reset' button, or save changes with the 'Save' button. If you have made changes to multiple files, the 'Save all' button can be used.

## File Editor
