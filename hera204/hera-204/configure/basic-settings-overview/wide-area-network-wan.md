# Wide Area Network (WAN)

## WAN IP address

Configure Ethernet WAN settings after using Setup Wizards to select an Ethernet WAN mode.

| # | Type                     | Sample value   | Explanation                                                                      |
| - | ------------------------ | -------------- | -------------------------------------------------------------------------------- |
| 1 | Address Assignment       | Static         | Static/DHCP. Determines whether the address is assigned manually or dynamically. |
| 2 | WAN IP Address           | 192.168.107.31 | In static mode, manually enter the Ethernet WAN address.                         |
| 3 | Netmask                  | 255.255.255.0  | In static mode, manually enter the Ethernet WAN subnet mask.                     |
| 4 | DNS Addresses            | 192.168.111.2  | In static mode, enter one or more DNS server addresses.                          |
| 5 | Obtain Gateway from DHCP | Yes/No         | Determines whether DHCP provides the gateway.                                    |
|   | Obtain DNS from DHCP     | Yes/No         | Determines whether DHCP provides DNS servers.                                    |
| 6 | Metric                   | 5              | Sets default-route priority when multiple routes exist.                          |
| 7 | Gateway                  | 192.168.107.1  | In static mode, the Ethernet WAN next-hop address.                               |
