# Router

The **Router** tab shows information about the router operating system.

![Router status tab](https://733576849-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2FY2LsJ6998Uo7AtYcmJWd%2Fuploads%2FKJ1kdwf4mGmhf9ttHuos%2Fsystem_status_screenshot.png?alt=media\&token=3e55afb2-062d-4047-9465-929294ec1fad)

| #  | Field name       | Sample value                                                                                       | Explanation                                                                                       |
| -- | ---------------- | -------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------- |
| 1  | Model            | Hera200                                                                                            | Model name of the router.                                                                         |
| 2  | Serial Number    | 04425751824320100036                                                                               | The serial number for the Hera 204 router.                                                        |
| 3  | Software Version | Hera200 1.0.5GA                                                                                    | Hera 204 router current software version.                                                         |
| 4  | Host name        | Hera200                                                                                            | The Hera 204 router's hostname. This can be used for communication with other LAN hosts.          |
| 5  | Firmware Version | OpenWrt 1.0.5GA r196-13e6ef9                                                                       | Hera 204 router current firmware version.                                                         |
| 6  | Kernel Version   | 4.14.275                                                                                           | The version of the Linux kernel currently running on the router.                                  |
| 7  | Local Time       | Thu Jun 05 2025 17:08:30                                                                           | Shows the current Hera 204 system time. Determined by the router's connected NTP server.          |
| 8  | Last Restart     | Thu Jun 05 2025 16:45:29                                                                           | Shows the system time of the last router reboot.                                                  |
| 9  | Uptime           | 2h 22m 59s                                                                                         | Indicates how long since the router booted. Reboots reset this timer.                             |
| 10 | Load average     | 0.63 - during the past minute; 0.64 - during the past 5 minutes; 0.50 - during the past 15 minutes | Reports the router activity level across specified intervals using an exponential moving average. |

| 12 | Site Name        | Eseye                                                                                              | User-defined site name.                                                                           |
| 13 | Site Location    | Eseye Office                                                                                       | User-defined site location.                                                                       |
| 14 | Site notes       | 1037-2                                                                                             | The running configuration version.                                                                |
