# Wide area network (WAN)

Displays information about the Ethernet WAN connection, if configured.

![WAN network information](https://733576849-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2FY2LsJ6998Uo7AtYcmJWd%2Fuploads%2FWVzcSnoECBpDOPknmWb9%2Fwide_area_network_wan_screenshot.png?alt=media\&token=ea3aa931-634a-42bf-968b-9dfacaf291f1)

| # | Field name         | Sample value  | Explanation                                               |
| - | ------------------ | ------------- | --------------------------------------------------------- |
| 1 | Address assignment | Static/DHCP   | Shows how the WAN interface gets an IP address.           |
| 2 | WAN IP address     | 192.168.2.14  | Address used by the router on the Ethernet WAN interface. |
| 3 | Net mask           | 255.255.255.0 | Defines the WAN network size.                             |
