# Mobile network

Displays information about mobile modem connections.

![Mobile network information](https://733576849-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2FY2LsJ6998Uo7AtYcmJWd%2Fuploads%2FxcMyzfR5uOWyqMvicW02%2Fmobile_network_screenshot.png?alt=media\&token=0eedb3a9-5a86-44b2-920f-59d5b6e63b06)

| # | Field name                | Sample value        | Explanation                                                                       |
| - | ------------------------- | ------------------- | --------------------------------------------------------------------------------- |
| 1 | Mobile Connection         | Enabled             | Shows whether the cellular interface is enabled or disabled.                      |
| 2 | IMEI                      | 359779081193837     | The modem's International Mobile Equipment Identity number.                       |
| 3 | Active SIM                | CHIP                | The current SIM card. Available SIMs are CHIP (embedded) and SIM.                 |
| 3 | IMSI of active SIM        | 204046996492361361  | Identifies the user in a cellular network.                                        |
| 4 | ICCID of active SIM       | 8999922112090023626 | The active SIM card's integrated circuit card identifier number.                  |
| 5 | Mobile Network Provider   | VODA UK (4G)        | Connected GSM network provider name.                                              |
| 6 | Mobile Network IP Address | 10.176.0.185        | Current IP address of the Hera 204 cellular interface.                            |
| 7 | Mobile Network Signal     | (graphic)           | Visually displays signal strength (RSSI). Hover to view a value such as `-65dBm`. |
| 8 | APN                       | eseye1              | APN used by the current cellular profile.                                         |

{% hint style="info" %}
The duplicate `3` numbering mirrors the source document.
{% endhint %}
