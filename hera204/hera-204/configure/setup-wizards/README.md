The **Setup Wizards** section configures the Hera 204 network topology.

### Connection modes

| Mode                           | Description                                                                                                              |
| ------------------------------ | ------------------------------------------------------------------------------------------------------------------------ |
| Cellular only                  | Uses the cellular radio as a single WAN interface. The Ethernet port operates as a LAN port.                             |
| Ethernet only                  | Uses Ethernet as a single WAN interface. The cellular radio is disabled. Connect LAN devices using Wi-Fi.                |
| Cellular protected by Ethernet | Uses cellular as the priority WAN interface. Ethernet provides backup WAN connectivity. Connect LAN devices using Wi-Fi. |
| Ethernet protected by Cellular | Uses Ethernet as the priority WAN interface. Cellular provides backup WAN connectivity. Connect LAN devices using Wi-Fi. |
