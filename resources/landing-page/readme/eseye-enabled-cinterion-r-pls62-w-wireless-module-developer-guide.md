# Eseye-enabled Cinterion® PLS62-W Wireless Module Developer Guide

Connect and manage an Eseye-enabled Cinterion® PLS62-W Wireless Module with AWS IoT Core. Covers provisioning, MQTT AT commands, configuration, and firmware updates.

### Guide overview

* Prepare AWS, configure AnyNet IRIS, and provision the module over cellular connectivity.
* Use ETM and MQTT AT commands to exchange messages and manage device shadows.
* Configure module parameters and apply firmware updates through AWS IoT jobs.
