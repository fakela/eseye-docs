# Manage SIM packages

The SIM packages page lists all of the packages associated with this account, and enables you to view and edit package information.

[![](../../.gitbook/assets/infinityclassic-0194-SimPackages_thumb_400_400.png)](../../.gitbook/assets/infinityclassic-0195-SimPackages.png)

### Search

Use Show to filter the packages to display: Select All, Active, Suspended, Legacy, Unsigned.

Select Search to update the records in the results table.

### Results

Select the export to PDF (![](../../.gitbook/assets/infinityclassic-0003-IconPdf_24x24.png)), export to CSV (![](../../.gitbook/assets/asset-test-icon-csv.png)) or print (![](../../.gitbook/assets/infinityclassic-0005-IconPrint_24x24.png)) buttons to export or print the information displayed on the page.

The following table describes the columns displayed for the SIM Audit Log records.

| Field        | Description                                                                                                                                                                                                                                                                                  |
| ------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Package ID   | Unique identifier for the [package](https://docs.eseye.com/Content/Billing/Billing_Packages.htm).                                                                                                                                                                                            |
| Package Name | Name of the package which typically contains information about the package items.                                                                                                                                                                                                            |
| Status       | The status of the package: Active Suspended Unsigned Legacy                                                                                                                                                                                                                                  |
| No. of SIMs  | The number of SIMs assigned to the package.                                                                                                                                                                                                                                                  |
| Actions      | ![](../../.gitbook/assets/infinityclassic-0031-IconEdit_24x24.png) – edit package details (friendly name, status) ![](../../.gitbook/assets/infinityclassic-0025-IconPdfBlack_24x24.png) – download [service contracts](https://docs.eseye.com/Content/Billing/Billing_Packages.htm#About2). |
