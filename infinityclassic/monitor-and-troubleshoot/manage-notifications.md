# Manage notifications

You can set up various system notifications to email you when any of the following events occur:

* New products and upgrades
* Purchase orders
* Reported network issues and maintenance
* Reported Infinity Classic application portal issues
* Reported management issues
* User permission changes

## Receiving notifications

To receive notifications in Infinity Classic:

1. Go to: > Notifications.
2. Select the Enable checkbox for each notification you want to receive.
