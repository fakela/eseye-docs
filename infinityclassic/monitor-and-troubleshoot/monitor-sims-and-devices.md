# Monitor SIMs and devices

This section describes how to monitor your SIMs and devices, including:

* Managing alert profiles
* Managing Reports
* Locating devices using a cellular connection
* Displaying SIM Timelines

## Viewing aggregated connection and data flow metrics

The Margay tool enables you to observe patterns, problems and anomalies with your network performance, using a web interface or the [Margay API](https://docs.eseye.com/Content/API/Margay/MargayAPIIntro.htm). You can access connection metrics, such as authentication and data throughput statistics, and display these by geographic region for a specified time period.

## Monitoring tools in Infinity Classic

The [SIM Actions](https://docs.eseye.com/Content/Analytics/SimActions.htm) on the SIMs > SIM List page also enable you to monitor the following:

* [Billing information](https://docs.eseye.com/Content/Analytics/SimActions.htm#Billing) including data, SMS and voice usage.
* [Messaging usage](https://docs.eseye.com/Content/Analytics/SimActions.htm#Messaging) including SMS, USSD and API messages.
* [RADIUS authentication information](https://docs.eseye.com/Content/Analytics/SimActions.htm#Radius) including session timings and MCC/MNC values.
* [NetFlow data](https://docs.eseye.com/Content/Analytics/SimActions.htm#NetFlow) including traffic flow and volume per SIM.
* Connectivity using the [Control Panel](https://docs.eseye.com/Content/Analytics/SimActions.htm#Control) which can send ping messages to the device.
