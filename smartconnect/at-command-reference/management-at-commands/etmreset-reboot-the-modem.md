# ETMRESET – reboot the modem

Reboots the modem.

| Type    | Syntax      | Response                                                                                                |
| ------- | ----------- | ------------------------------------------------------------------------------------------------------- |
| Execute | AT+ETMRESET | The module reboots. OK +ETM: REBOOTING NORMAL POWER DOWN RDY APP RDY +ETM: SYSSTART +ETM: IDLE or ERROR |

#### Example

at+etmreset

OK

+ETM: REBOOTING

NORMAL POWER DOWN

RDY

APP RDY

+ETM: SYSSTART

+ETM: IDLE
