# Management AT commands

AnyNet SMARTconnect™ Management AT commands enable you to configure and manage AnyNet SMARTconnect™ and the module.

## Where to next?

* AnyNet SMARTconnect™ AT Commands
* ETMCFG – read and write configuration file values
* ETMCFGCHECK – checks if a new AnyNet SMARTconnect™ configuration file is available
* ETMFWCHECK – checks for updates to the AnyNet SMARTconnect™ application
* ETMHFWCONF – confirms the new host firmware is applied
* ETMHFWGET – checks for new host firmware
* ETMHFWREAD – reads a section of the new host firmware image
* ETMINFO – displays AnyNet SMARTconnect™ and device information
* ETMLW – handles the LwM2M protocol
* ETMRESET – reboot the modem
* ETMSTATE – check current state
* +ETM Unsolicited Response Codes (URCs)
* MQTT AT commands
* MQTT Rx Queue
* General AT Commands
