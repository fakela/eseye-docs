# ETMSTATE – check current state

Checks the current state of the LTE IoT 2 click.

| Type  | Syntax                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                | Response                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| ----- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Test  | AT+ETMSTATE=?                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         | +ETMSTATE: 0: Idle 1: Awaiting keys 2: Network connecting 3: Establishing TLS 5: Establishing data-link 6: Connected 7: Subscribed 8: UDP active 9: Error OK where the modem: 0 – is ready to receive commands. 1 – has registered to the network and is waiting for certificate delivery to complete on the SIM. 2 – is waiting to establish a network connection. 3 – is establishing end-to-end security of data, using the Transport Layer Security protocol. 4 – this state is currently unused. 5 – is establishing a connection to AWS in order to transfer data. 6 – has connected to the MQTT broker. 7 – is subscribed to MQTT topics. 8 – User Datagram Protocol is ready for use. 9 – the device or connections have failed. |
| Read  | AT+ETMSTATE?                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          | +ETMSTATE: OK or ERROR                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| Write | AT+ETMSTATE= where is the command, either: 0 – disable state change URC 1 – enable state change URC "powerdown" – turn off modem when it is not in the busy state For information about the busy state, see ETMINFO – displays AnyNet SMARTconnect™ and device information. "powerdownnow" – turn off modem immediately without waiting for pending actions to complete "startlwm2m" – start the LwM2M protocol "startmqtt" – start AnyNet Secure MQTT application "startudp" – start UDP telemetry application "stop" – stop AnyNet Secure MQTT, LwM2M, or UDP telemetry application. Use this to cleanly shutdown before power off. | OK After AT+ETMSTATE="stop", AnyNet SMARTconnect™ returns to idle and the following response occurs: +ETM: IDLE or +ERROR:                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |

#### Example

AT+ETMSTATE?

+ETMSTATE: 0

OK
