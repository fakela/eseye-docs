# Using the AnyNet SMARTconnect™ configuration file

Eseye-enabled module operating parameters are contained in a module-specific configuration file.

The Eseye-enabled Quectel module operating parameters are contained in the configuration file, which you can find here: /datatx/eseyeconfig.ini.

You can use the configuration file to set the following parameters:

* Operational
* Network
* Application
* Host
* Config
* MQTT
* UDP
* SMS
* Location

{% hint style="info" %}
If this file does not exist, a backup configuration file is used instead: /datatx/eseyeconfig.bak. If neither file exists, AnyNet SMARTconnect™ uses internal default configuration parameters.
{% endhint %}

To display the contents of the current configuration file:

* Send `AT+ETMCFG="show"`.

To save the current configuration:

* Send `AT+ETMCFG="save"`.

For more information, see ETMCFG – read and write configuration file values.

{% hint style="info" %}
To update the configuration file over the air, see Updating the modem firmware using AWS IoT jobs – Quectel module.
{% endhint %}

You can deploy the configuration file using any of the following network protocols: http, https, or tftp.

You can trigger an update using either SMS, MQTT, or AT command.

The .ini file is divided into sections, denoted by square brackets. Each section has parameters listed underneath it.

{% hint style="info" %}
To view an example configuration file, see Example content – AnyNet SMARTconnect™ configuration file.
{% endhint %}

## Example content – AnyNet SMARTconnect™ configuration file

The following configuration example is for a battery operated device that connects to the network at random times, when in use.

* The microcontroller (MCU) has very limited programming capacity.
* It uses elliptic-curve cryptography (ECC).
* The device data is sent to AWS.
*   Device updates and so on are fetched from AWS. In line with best practice, the device initiates all communication with AWS.

    For more information, see Device configuration best practices.

{% hint style="warning" %}
The comments within the example do not exist in the configuration file on the device.
{% endhint %}

\[operation]

mode=mqtt

; Operating in MQTT mode by default

irqmode=none

irqpin=26

apptrace=1

nvqueuetrace=1

teletrace=1

attrace=1

nvqueuemaxsize=2048

nvqueue\_enable=1

update\_autoreboot=0

; Disables autoreboot. The device is not designed to handle the

; modem disconnecting and connecting in an uncontrolled way.

; By disabling autoreboot, then using AT+ETMSTATE="powerdown" and

; waiting for a POWERED DOWN URC, the device can process an OTA

; without disrupting the normal flow of operation.

; To set this up, use the AT+ETMSTATE=1 command to enable state change URC.

time\_format=%F,%T%z

time\_urc=none

enable\_time\_zone=0

time\_zone=0

; Sets the time and timezone to match where the device physically exists.

; The timezone value is passed to a server-side platform for further processing.
