# Interacting with the AWS IoT shadow

## Interacting with the AWS IoT shadow

You can configure the Quectel module to provide a persistent representation of your thing in the cloud, for use by applications or devices. You can publish current and updated state information to a shadow, and your thing can synchronize its state when it connects.

For information about enabling shadow use, see [emqpersist-report-a-set-value-to-the-device-shadow.md](../at-command-reference/mqtt-at-commands/emqpersist-report-a-set-value-to-the-device-shadow.md "mention").

For detailed AWS information about using shadows, see Simulating Device Shadow service communications.
