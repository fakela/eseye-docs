# How to manage Infinity reports

Infinity reports offer structured insights into your SIM estate, helping you to monitor SIM and network performance and compliance, analyse financial data, and track connectivity. Use the reports to identify usage trends, resolve issues, and make informed decisions to optimise your resources effectively.

You can view, download, and generate on-demand reports. For more information, see [#viewing-infinity-reports](about-infinity-reports.md#viewing-infinity-reports "mention").

You can configure schedules to generate and distribute reports at set intervals. For more information, see [Create a scheduled report](https://app.gitbook.com/s/WyhQkIlNdafYQukxlk4L/reporting/create-a-scheduled-report "mention").

## Reporting services developer documentation

We offer report APIs and object reference tables so that you can build your own reports. For more information, see the [Overview](https://app.gitbook.com/s/0xQKujz8nVihyxgGvU7r/ "mention").
