# How to manage portfolios

A portfolio is a collection of a customer's account information, including the company name, billing information such as tax and account currency details, associated portal, postal addresses, and user information.

You will only have access to managing portfolios if you have the relevant permissions.

Depending on your permissions, you can view, create, activate, update and delete portfolios, addresses and users. For more information, see [About viewing the current portfolio in Infinity](about-viewing-the-current-portfolio-in-infinity.md).

For user roles and permissions, see About user roles.
