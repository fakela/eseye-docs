# About viewing the current portfolio in Infinity

To access the current portfolio in Infinity:

1. On the left menu, select Portfolio.
2.  Select Your Portfolio to view an overview of the current portfolio, including address and user information.

    ![](../.gitbook/assets/Infinity_YourAccountPage.png)

    The portfolio overview contains the following fields:

    | Field            | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
    | ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
    | Portfolio name   | A friendly name for identifying the portfolio, usually the company name followed by a geographic region or project.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
    | Company          | A unique identifier assigned to the company when it is officially registered with a government authority or regulatory body.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
    | Country          | The country where the invoice address is located.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
    | Billing Currency | The three-digit ISO 4217 alphabetic currency code assigned to the portfolio.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
    | Addresses        | The addresses associated with the current portfolio.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
    | Users            | <p>The users associated with the current portfolio:</p><ul><li><strong>Username:</strong> The unique user account name for the current portfolio.</li><li><strong>Name:</strong> The user's first and last names.</li><li><strong>Status:</strong> Active, Inactive, Verified, or Unverified.</li><li><strong>Active:</strong> Users who can log in and access the portal.</li><li><strong>Inactive:</strong> Users whose account is suspended because they have not interacted with the portal for a specified period.</li><li><strong>Verified:</strong> Users who have authenticated their account through the referral code link.</li><li><strong>Unverified:</strong> Users who have not authenticated their account through the referral code link.</li><li><strong>Email:</strong> A valid business email address where the user receives emails.</li></ul> |
