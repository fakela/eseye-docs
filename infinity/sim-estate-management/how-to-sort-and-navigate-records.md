# How to sort and navigate records

## Sort search results

In the search results view, select a column name to change its sort order:

* Ascending ![](<../.gitbook/assets/image (10).png>) sorts text from a to z and numbers from 1 to 9.
* Descending ![](<../.gitbook/assets/image (11).png>) sorts text from z to a and numbers from 9 to 1.

## View more results

{% hint style="info" %}
#### Navigating multiple result pages

**View More** is available only when a page has more results to show.
{% endhint %}

Some pages return results in a continuous list. At the end of the list, select **View More** to see additional items.
